# For Malu, with love 💗

A mobile-first romantic surprise website built with plain HTML, CSS, and JavaScript.

## Features
- Multiple interactive story pages with progress indicator
- Playful questions with a dodging "No" button
- Teasing multiple-choice screen
- Click-to-open letter with a few cute staged clicks
- Final love reveal, floating hearts, responsive layout
- No photos, backend, database, analytics, or build tools

## Before publishing
Your supplied date (28 February 2026) and “together for 9 years” don't match. Both details have been preserved as requested, and the page includes a gentle reminder. Edit `script.js` to correct one before sharing if needed.

## Test locally
Extract the ZIP and open `index.html` in a browser. Test the buttons on mobile width. For the most reliable testing, use VS Code Live Server or another local static server.

## Publish free with GitHub Pages
1. Sign in at https://github.com/
2. Create a **public** repository such as `for-malu`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for the published URL, typically `https://YOUR-USERNAME.github.io/for-malu/`.
7. Test the link on a phone before sending it.

## Privacy
The site does not collect or submit answers. A public GitHub Pages site is accessible to anyone who has the link, so avoid adding private or sensitive information.
